# 🏃 STRAVA FITNESS DATA ANALYTICS

## 📊 Interactive Fitness & Wellness Analytics Dashboard

An end-to-end Data Analytics project designed to analyze fitness activity, 
sleep patterns, calorie expenditure, intensity, and user behavior using 
Python, SQL, DuckDB, Pandas, Plotly, and Streamlit.

---

## 🎯 Project Overview

This project transforms raw fitness tracking data into interactive 
business-style insights through exploratory data analysis, SQL analytics,
statistical analysis, and interactive visualization.

---

## ❗ Problem Statement

Fitness platforms generate large volumes of activity and wellness data.

The objective is to analyze this data and identify meaningful patterns 
related to:

- Physical activity
- Daily steps
- Calories burned
- Distance traveled
- Activity intensity
- Sleep duration
- Sedentary behavior
- Weekend vs weekday behavior

---

## 🎯 Objectives

1. Analyze daily activity patterns.
2. Understand user engagement.
3. Analyze calorie expenditure.
4. Examine sleep behavior.
5. Compare weekday and weekend activity.
6. Identify relationships between activity and sleep.
7. Build interactive analytical dashboards.
8. Generate actionable fitness insights.

---

## 💼 Business Use Cases

### Fitness Engagement
Identify user activity patterns.

### Wellness Analytics
Understand relationships between activity and sleep.

### Behavioral Segmentation
Identify different activity behavior patterns.

### Product Analytics
Support fitness-product engagement strategies.

### Personalized Insights
Provide data-driven recommendations based on activity behavior.
